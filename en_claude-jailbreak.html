01

Document analysis and editing

For a document task in Claude, separate the source material from your instructions. Specify whether you want a summary, an argument comparison, an edit or questions about the text. Set clear review criteria, such as preserving the author's meaning and identifying claims not supported by the source.

02

Example: find a contradiction in a document

<document>
Section 2: the report must be submitted within 30 days of project completion.
Section 7: the final report must be submitted no later than 45 days after project completion.
</document>
<task>
Use only this document. Make a table with section, deadline and exact quotation. Identify the inconsistency and ask the author one clarification question. Do not choose the “correct” deadline or add legal conclusions.
</task>

03

Checking Claude’s quotations and conclusions

The table should retain both deadlines, 30 and 45 days, with the correct section numbers. Quotations should match the source. A useful clarification question asks whether the deadlines refer to the same report or different documents; the source does not resolve that ambiguity.

Do not mark the answer as accurate if it silently chooses a deadline, presents a paraphrase as a quotation or cites a law absent from the source. For a real file, check that its text was extracted completely before evaluating the analysis.

This is a practice example with explicit assessment criteria, not a record of a completed Claude test. For your comparison, retain the model name, date, prompt and full response.

04

Working with long text and clarification

Separate source material from instructions with descriptive tags such as document and task. For a long file, identify the sections to inspect, the question to answer and the output format. Ask for unsupported claims to be marked explicitly.

Avoid combining editing and fact-checking in one vague request. Obtain an issue list first, request an edit next, and check that the revised text preserves the source meaning. Match the selected JailBrok material to the model name shown in your Claude interface.

Official documentation: Claude Docs

05

How to evaluate the result

Choose a file intended for the Claude model you are using. A long or confident answer is not proof of accuracy: check quotations, figures and conclusions against the document. For editing, first request a change list, then assess the revised text against the same criteria.
