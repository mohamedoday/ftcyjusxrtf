01

Writing, explanations and programming

Before choosing a ChatGPT prompt, define your audience, goal and output format. For coding tasks, include a small input example and the expected result. For writing, specify the tone and length. These details help you choose a suitable library entry instead of applying the same template to every task.

02

Example: a summary without invented details

Task: write a short announcement using only the source.
Source: “A photography workshop takes place on 18 November at 19:00. It lasts 90 minutes and has 20 places. The price is not specified.”
Write a two-sentence announcement. Preserve the date, time, duration and number of places. Do not invent a price, address or host. After the announcement, list the missing information separately.

03

How to compare two prompts on this task

Use a separate new conversation for each prompt and keep the source text identical. Record the displayed model name and test date. Changing the prompt, model and source together makes it impossible to tell which change affected the result.

Check four facts: 18 November, 19:00, 90 minutes and 20 places. Then check that the announcement has two sentences and contains no invented price, address or host. These criteria are more useful than judging whether an answer sounds impressive.

The example is an open practice task, not a published model test result. Repeat the comparison and retain complete answers before drawing conclusions about reliability.

04

If ChatGPT does not follow the format

First remove conflicting requirements and request one output format. Provide a short example of the desired structure using different data. If the issue persists, name the exact problem, such as asking for exactly two sentences with questions in a separate block.

A jailbreak prompt does not change your ChatGPT plan, unlock an unavailable model or guarantee factual accuracy. A JailBrok subscription provides its prompt library; access to the AI service is separate.

05

How to evaluate the result

Earlier messages in a long conversation can affect the result. Compare prompts on the same task and avoid stacking contradictory instructions. If an answer is inaccurate, clarify the inputs and verify facts or code separately. A different model version may require a different library file.
