Defining tasks for project work

For Antigravity, specify a concrete project outcome: a bug fix, a prototype or an interface change. State constraints, completion criteria and how the result will be verified. Break multi-step work into smaller tasks with outcomes you can check.

How to evaluate the result

Your choice of environment does not remove the need to check the selected model. Match the prompt file to its instructions and the actual result. For project changes, assess the resulting files, working behavior and preservation of existing functionality, not just the chat response.
